# ⚾ KBO Team Simulation

KBO 팀별 타격·투구 데이터를 기반으로 팀 전력을 분석하고, 서로 다른 시즌의 팀들이 대결하는 가상 시즌을 구현한 프로젝트입니다.

Random Forest 회귀 모델로 팀의 승률을 예측하고, 피타고리안 승률과 Log5 공식, 몬테카를로 시뮬레이션을 결합해 가상 리그의 기대 승수와 우승 확률을 계산했습니다.

## 프로젝트 목표

- 2001~2021년 KBO 팀별 타격·투구 데이터 통합
- 타격 및 투구 지표를 활용한 팀 승률 예측
- 서로 다른 시즌의 팀 간 승리 확률 계산
- 144경기 가상 시즌 반복 시뮬레이션
- 시뮬레이션 결과 시각화

## 데이터

### 타격 데이터

주요 지표는 다음과 같습니다.

- 타율(AVG)
- 출루율(OBP)
- 장타율(SLG)
- OPS
- 경기당 득점
- 홈런
- 안타
- 도루
- 볼넷
- 삼진

### 투구 데이터

주요 지표는 다음과 같습니다.

- 평균자책점(ERA)
- WHIP
- 경기당 실점
- 9이닝당 탈삼진
- 9이닝당 볼넷
- 피안타
- 피홈런
- 승리 및 패배

타격 데이터와 투구 데이터는 `year`와 `team`을 공통 키로 사용하여 팀-시즌 단위로 병합했습니다.

## 분석 방법

### 1. 데이터 전처리

- 결측치 확인 및 처리
- 타격·투구 데이터 병합
- 파생 변수 생성
- StandardScaler를 이용한 특성 표준화

### 2. 승률 예측 모델

Random Forest Regressor를 사용해 팀-시즌의 승률을 예측했습니다.

모델에 사용한 10개의 특성은 다음과 같습니다.

| 구분 | 특성 |
|---|---|
| 타격 | OPS, 타율, 경기당 득점, 홈런 |
| 투구 | ERA, WHIP, 9이닝당 탈삼진, 9이닝당 볼넷, 경기당 실점 |
| 파생 변수 | 피타고리안 승률 |

주요 하이퍼파라미터는 다음과 같습니다.

```python
RandomForestRegressor(
    n_estimators=300,
    max_depth=6
)
```

### 3. 피타고리안 승률

팀의 득점과 실점을 이용해 팀 전력에 가까운 승률을 계산했습니다.

```text
Pythagorean Winning Percentage
= RS^k / (RS^k + RA^k)
```

- `RS`: 득점
- `RA`: 실점
- `k`: 1.83

### 4. Log5 공식

두 팀의 승률을 바탕으로 맞대결 승리 확률을 계산했습니다.

```text
P(A beats B)
= (Pa - Pa × Pb) / (Pa + Pb - 2 × Pa × Pb)
```

- `Pa`: A팀의 예상 승률
- `Pb`: B팀의 예상 승률

### 5. 몬테카를로 시뮬레이션

- 참가 팀의 대진을 144경기에 균등하게 배분
- Log5 공식으로 경기별 승리 확률 계산
- 난수를 이용해 각 경기의 승패 결정
- 가상 시즌을 2,000회 반복
- 팀별 기대 승수와 우승 확률 계산

다음 네 팀을 대상으로 144경기 가상 시즌을 2,000회 시뮬레이션했습니다.

| 순위 | 팀-시즌 | 모델 예상 승률 | 기대 승수 | 우승 확률 |
|---:|---|---:|---:|---:|
| 1 | 2002 삼성 라이온즈 | 0.6266 | 80.2승 | 58.6% |
| 2 | 2012 삼성 라이온즈 | 0.6117 | 77.2승 | 32.0% |
| 3 | 2002 기아 타이거즈 | 0.5775 | 70.4승 | 8.8% |
